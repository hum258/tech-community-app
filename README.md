# Tech Community App

واجهة أولية لتطبيق مجتمع تقني على Android وiOS باستخدام Expo وReact Native.

## تجربة التطبيق

### تشغيله على الهاتف عبر Expo Go
1. ثبّت Node.js على الكمبيوتر وثبّت Expo Go على هاتف Android أو iPhone.
2. نزّل المستودع وافتح مجلده في الطرفية.
3. نفّذ:

```bash
npm install
npx expo start
```

4. امسح رمز QR الظاهر في الطرفية باستخدام Expo Go. يجب أن يكون الكمبيوتر والهاتف على الشبكة نفسها غالباً.

### إنشاء APK تجريبي من السحابة
ملف `eas.json` يحتوي إعداد بناء تجريبي بصيغة APK. بعد تسجيل الدخول إلى حساب Expo من الطرفية:

```bash
npx eas-cli build --platform android --profile preview
```

سيحتاج البناء السحابي إلى حساب Expo وإعداد المشروع أول مرة. لم يتم إنشاء APK بعد.

### فحص TypeScript
```bash
npm install
npm run typecheck
```

## الموجود حالياً

- واجهة داكنة باللون الكحلي والأزرق السماوي.
- تبديل العربية والإنجليزية.
- موجز منشورات تجريبي مع تصفية حسب التخصص والبحث.
- تفاعلات محلية: إعجاب، حفظ، وإنشاء منشور تجريبي.
- شريط تنقل رئيسي: الرئيسية، استكشف، المجتمعات، الرسائل، حسابي.\n- نموذج تسجيل تجريبي لاختيار حساب شخصي أو شركة.\n- معاينة شارات توثيق مجانية: زرقاء للأفراد وفضية للشركات.\n- البحث عن التخصصات والانضمام التجريبي للمجتمعات والتعليقات ومشاركة المنشورات.

## ملاحظة

هذه نسخة واجهة أولية (Frontend Prototype). تسجيل الدخول عبر Google، قاعدة البيانات، الرسائل الحقيقية، الإشعارات، لوحة الإدارة، ومنح شارات التوثيق الفعلية لم تُربط بعد. شارات التوثيق في هذه النسخة مجرد معاينة تصميمية؛ ستبقى مجانية وفق الخطة، مع شارة زرقاء للحسابات الشخصية وفضية للشركات بعد مراجعة الإدارة. الاسم الظاهر مؤقت إلى حين اختيار الاسم النهائي للمنصة.
