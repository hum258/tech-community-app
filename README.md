# Tech Community App

واجهة أولية لتطبيق مجتمع تقني على Android وiOS باستخدام Expo وReact Native.

## تشغيل المشروع

1. ثبّت Node.js على جهازك.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ:

```bash
npm install
npx expo start
```

4. امسح رمز QR باستخدام Expo Go على هاتفك، أو شغّل محاكي Android/iOS.

## الموجود حالياً

- واجهة داكنة باللون الكحلي والأزرق السماوي.
- تبديل العربية والإنجليزية.
- موجز منشورات تجريبي مع تصفية حسب التخصص والبحث.
- تفاعلات محلية: إعجاب، حفظ، وإنشاء منشور تجريبي.
- شريط تنقل رئيسي: الرئيسية، استكشف، المجتمعات، الرسائل، حسابي.

## ملاحظة

هذه نسخة واجهة أولية (Frontend Prototype). تسجيل الدخول عبر Google، قاعدة البيانات، الرسائل الحقيقية، الإشعارات، لوحة الإدارة، التوثيق، والميزات الخلفية لم تُربط بعد. الاسم الظاهر مؤقت إلى حين اختيار الاسم النهائي للمنصة.
